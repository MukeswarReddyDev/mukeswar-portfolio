# 🌟 Mukeswar Reddy Bandlapalli - Full Stack Java Developer Portfolio

A premium, highly interactive, dark-themed developer portfolio website built with modern design principles (glassmorphism, vibrant neon glow gradients, and micro-animations) using **only HTML, CSS, and Vanilla JavaScript**.

🔗 **Live Demo**: [https://mukeswarreddydev.github.io/mukeswar-portfolio/](https://mukeswarreddydev.github.io/mukeswar-portfolio/)

---

## 🚀 Key Features

*   **Premium Aesthetics**: Modern dark theme featuring smooth gradient text effects, neon mesh glowing backgrounds, glassmorphism containers, and interactive floating badges.
*   **Dynamic Typing Effect**: Cycles through developer titles like *Full Stack Java Developer*, *Software Developer*, *Java Specialist*, and *Web Developer*.
*   **Fully Responsive Timeline**: Displays structured timeline sections for **Work Experience** (e.g., Software Developer Intern at Tap Academy) and **Education** (B.Tech, Diploma, SSC).
*   **Interactive Projects Filtering**: Users can filter featured projects dynamically between *Java Applications* and *Web Frontends* without page reloads.
*   **Direct Resume Download**: Dedicated CTA button in the navigation bar to download the resume directly.
*   **Video Tour integration**: A direct "Watch Video" walkthrough button in the hero section to see a video demonstration of the developer's work.
*   **Dynamic Contact Form**: Complete with front-end validation and simulated toast alerts (success/error states).
*   **Optimized Inline SVGs**: Scalable and lightweight vectors for all social media (GitHub, LinkedIn, Gmail) and contact icons, ensuring quick loading and reliable rendering.

---

## 🛠️ Technologies Used

*   **Structure**: HTML5 (Fully semantic)
*   **Styling & UI Framework**: [Tailwind CSS](https://tailwindcss.com/) (CDN integration with custom extension parameters)
*   **Custom styles**: Vanilla CSS (`style.css` for keyframe floating animations, glass navbars, and neon card borders)
*   **Logic & Animation**: Vanilla JavaScript (`script.js` for mobile navigation toggle, typing animations, scroll-spy link tracking, and category filters)
*   **Icons**: Inline SVGs

## 💻 Running the Project Locally

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/MukeswarReddyDev/mukeswar-portfolio.git
    ```
2.  **Navigate to the folder**:
    ```bash
    cd mukeswar-portfolio
    ```
3.  **Open index.html**:
    Double-click `index.html` or open it with any modern web browser (Chrome, Edge, Safari, Firefox) to view the page.
