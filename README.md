# 🌟 Bandlapalli Mukeswar Reddy - Java Full-Stack Developer Portfolio

A premium, highly interactive, dark-themed developer portfolio website built with modern design principles (glassmorphism, vibrant neon glow gradients, and micro-animations) using **HTML5, Tailwind CSS, Vanilla CSS, and Vanilla JavaScript**.

🔗 **Live Demo**: [https://mukeswarreddydev.github.io/mukeswar-portfolio/](https://mukeswarreddydev.github.io/mukeswar-portfolio/)

---

## 🚀 Key Features

*   **Premium Aesthetics**: Modern dark theme featuring smooth gradient text effects, neon mesh glowing backgrounds, glassmorphism containers, and interactive floating badges.
*   **Dynamic Typing Effect**: Cycles through developer titles like *Java Full-Stack Developer*, *Software Developer*, *Spring Boot & REST API Dev*, and *Java Specialist*.
*   **Fully Responsive Timelines**: Displays structured timelines for **Work Experience** (Software Developer Intern at Tap Academy, Electronics Intern at Smile Electronics) and **Education** (B.Tech, Diploma, SSC).
*   **Interactive Projects Filtering**: Users can filter featured projects dynamically between *Full-Stack Java* and *Core Java & OOP* without page reloads.
*   **Featured Projects Showcased**:
    *   **Job Portal Management System**: Monolithic, layered REST API application using Java 17, Spring Boot, Spring Data JPA, Hibernate, MySQL, Spring Security, and JWT authentication with role-based access for Admin, Recruiter, and Job Seeker.
    *   **FoodieHub — Food Delivery Web App**: Full-stack MVC + DAO architecture with Java, Servlets, JSP, JDBC, and MySQL.
    *   **Student Management System**: Console-based application using Core Java, OOP principles, and ArrayList with full CRUD and duplicate ID validation.
*   **Direct Resume Download**: Dedicated CTA button in the navigation bar to view/download the updated PDF resume directly.
*   **Dynamic Contact Form**: Form submission integrated with email delivery and responsive toast notifications.
*   **Optimized Inline SVGs & Lucide Icons**: Scalable and lightweight vectors for all social media (GitHub, LinkedIn, Gmail) and contact icons, ensuring quick loading and reliable rendering.

---

## 🛠️ Technologies Used

*   **Structure**: HTML5 (Fully semantic)
*   **Styling & UI Framework**: [Tailwind CSS](https://tailwindcss.com/) (CDN integration with custom extension parameters)
*   **Custom styles**: Vanilla CSS (`style.css` for keyframe floating animations, glass navbars, and neon card borders)
*   **Logic & Animation**: Vanilla JavaScript (`script.js` for mobile navigation toggle, typing animations, scroll-spy link tracking, and category filters)
*   **Icons**: Lucide Icons CDN & inline SVG vectors

## 💻 Running the Project Locally

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/MukeswarReddyDev/mukeswar-portfolio.git
    ```
2.  **Navigate to the folder**:
    ```bash
    cd mukeswar-portfolio
    ```
3.  **Open index.html**:
    Double-click `index.html` or open it with any modern web browser (Chrome, Edge, Safari, Firefox) to view the page.
